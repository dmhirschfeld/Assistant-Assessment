# Assistant Assessment Platform

An hour-long, job-realistic pre-hire test for executive and administrative assistants. Employers invite candidates, candidates complete eight timed sections, and employers get a scored report with red flags to discuss in interviews.

- **Prototype / spec:** open `Assistant Assessment Platform_ Clickable Prototype.html` in a browser. Turn on **Developer notes** in the top bar to see what each screen needs.
- **Requirements:** [`docs/requirements.md`](docs/requirements.md)
- **Status:** planning — no application code yet.
